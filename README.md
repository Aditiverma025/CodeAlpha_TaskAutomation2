CodeAlpha Task Automation
Email Extractor Automation Project
Task Automation is a Python-based automation project created as part of the CodeAlpha Python Programming Internship.

This project automates a real-life repetitive task: extracting email addresses from a text file and saving them into another file. It also generates a detailed automation report.

Project Objective
The objective of this project is to automate the process of finding email addresses from a text document.

Instead of manually reading a file and copying emails one by one, this program automatically scans the file, extracts valid email addresses, removes duplicates, saves the results, and generates a report.

Features
Reads text from an input file
Extracts valid email addresses automatically
Removes duplicate email addresses
Sorts extracted emails
Saves emails into an output text file
Generates an automation report
Allows user to add new text into the input file
Allows user to view input file content
Allows user to view extracted emails
Menu-driven interface
Beginner-friendly Python code
Uses only Python standard libraries
